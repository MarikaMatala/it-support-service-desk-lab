# IT Support & Service Desk Learning Lab

A personal learning and portfolio project focused on IT support, service desk workflows, technical troubleshooting, systems, networking, and clear technical documentation.

The project records practical exercises completed in learning environments and simulators, along with the investigation process, tools used, experiments, outcomes, time spent, and lessons learned.

> **Project status:** Work in progress  
> **Project type:** Independent learning and portfolio project

## Project goals

- Practise structured IT troubleshooting and problem-solving.
- Build familiarity with common IT support tasks and service desk scenarios.
- Explore networking, operating systems, identity and access management, and cybersecurity.
- Improve technical research and documentation skills.
- Track learning progress and actual time spent on exercises.
- Create an evidence-based record of skills practised and knowledge gained.

## Learning areas

| Area | Focus |
| --- | --- |
| Helpdesk | Service desk workflows, user support, and support scenarios |
| Networking | Network fundamentals, connectivity, DNS, and diagnostic tools |
| Active Directory | Directory services, accounts, groups, and access management |
| Troubleshooting | Identifying, investigating, and resolving technical problems |
| Cybersecurity | Security fundamentals and safe security exercises |
| Operating Systems | Operating system concepts, configuration, and support |

## Exercise documentation

Each exercise is documented using [the exercise template](templates/exercise-template.md).

A record may include:

- Exercise objective and initial situation
- Problem analysis and troubleshooting plan
- Tools, commands, and resources used
- Experiments, observations, and unsuccessful attempts
- Final solution and verification
- Actual time spent
- Challenges, decisions, and lessons learned
- Evidence, references, and personal reflection

The aim is to document the reasoning and learning process, not just the final answer. Unsuccessful attempts and partially completed exercises can also provide useful learning evidence.

## Learning platform

One of the learning resources used in this project is [ServiceDesk Simulator](https://servicedesk-simulator.com/).

Exercises may also use other learning resources, tools, and practice environments. The platform and environment used are identified in each exercise record.

## Progress tracking

Progress is recorded through individual exercise documents and reflection notes.

Time entries represent actual tracked time where available. Unmeasured time is left unspecified rather than presented as an estimate.

## Documentation and integrity

- Exercise descriptions are written in my own words.
- Third-party task descriptions and protected materials are not reproduced.
- Simulator-based exercises are clearly identified as simulated practice, not professional work experience.
- Screenshots and examples are checked for credentials, personal data, tokens, and other sensitive information before publication.
- Results and completion status are recorded honestly, including partial results and unsuccessful attempts.
