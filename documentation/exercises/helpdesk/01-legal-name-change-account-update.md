## 2. Objective

The exercise involved processing an account update following a user's legal name change. The requested changes included updating the account's display name and email address while keeping the previous email address available as an alias.

## 3. Initial situation

A service request had been submitted asking IT support to update an employee account after an approved legal name change. The required account changes were described in the simulated ticket.

No original ticket text, names, email addresses or other identifying details are reproduced in this report.

## 4. Problem analysis

The task was an account administration request rather than a technical fault. The main requirements were to:

- Update the account's display name.
- Change the account's primary email address.
- Retain the previous email address as an alias.

The requested changes needed to be completed in the simulator before the service request could be closed.
